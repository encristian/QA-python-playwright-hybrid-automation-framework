# Python Playwright Hybrid Automation Framework

A hybrid UI and API test automation framework developed with Python, Playwright and PyTest.

## Application Under Test

Automation Exercise, an e-commerce application used for automation testing practice.

## Project Objectives

- Automate critical user interface scenarios
- Test REST API endpoints
- Combine UI and API testing
- Implement network interception and API mocking
- Run tests across multiple browsers
- Execute automated tests through GitHub Actions

## Technologies

- Python
- Playwright
- PyTest
